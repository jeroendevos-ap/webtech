# GIT install (windows stappenplan)
- vscode sluiten
- lege folder aanmaken (bv webtech-repo)
- git installeren: download van git-scm.com / bij installatie op alles 'next' klikken
- vscode starten
- in vscode : terminal openen (Terminal > New terminal)
- in terminal : git --version
- in terminal : git config => email en naam invullen
    git config --global user.name "Voornaam Achternaam"
    git config --global user.email "jij@student.ap.be"
- in vscode : file > open folder (lege folder webtech-repo kiezen)
- in browser -> github : repo url kopieren vanuit github (groene knop '<> Code') : opgelet HTTPS
- in vscode : source control > initialise git repo
- in vscode : source control > clone > repo ingeven
    klik op 'always'
